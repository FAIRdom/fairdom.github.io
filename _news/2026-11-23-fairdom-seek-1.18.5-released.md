---
title: "FAIRDOM-SEEK version 1.18.5 released"
---

A new version of [FAIRDOM-SEEK](/fairdomseek), version **1.18.5**, is now available 

This is a patch release that uses updated versions of Ruby and Nginx to fix discovered vulnerabilities. It mainly affects the Docker containers, but if running locally you should at least update to Ruby 3.3.14. If you use Nginx, check it has been updated with `apt` (or other package manager).

**We recommend upgrading as soon as possible**

Details on installing SEEK can be found in our Documentation, at [https://docs.seek4science.org/get-seek.html](https://docs.seek4science.org/get-seek.html) – including running with [Docker](https://www.docker.com/).

The upgrade guide can be found in the usual place at [https://docs.seek4science.org/tech/upgrading.html](https://docs.seek4science.org/tech/upgrading.html)
